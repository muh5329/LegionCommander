# Legion Commander

A top-down Godot game inspired by **Pikmin** and **Patapon**. Command your legion with mouse clicks, explore, and conquer!

## Features

- **Top-down squad control**  
- **Mouse-based commands**  
- **Patapon-inspired rhythm and visuals**  
- **Tactical gameplay**

## Controls

- **Left Click:** Move/Command your legion
- **Right Click:** Special actions (contextual)
